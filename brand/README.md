## Untzel (`untzel/`)

The Untzel mark, designed in 10/2026 (the "Untz" direction): the "un" of the name is a single
∪∩ wave stroke, the sound wave of the kick drum, in `flare #F65D00`; the rest of the name uses
the same round-capped stroke as the interface icons. It is a Techno Inspire trademark, under
the same rules as [`TRADEMARKS.md`](../TRADEMARKS.md).

| File | Use |
|---|---|
| `untzel-icon.svg` | icon with rounded corners (favicon, screens, materials) |
| `untzel-icon-square.svg` | full-bleed icon, source of the app PNGs (the system rounds it) |
| `untzel-icon-180.png`, `untzel-icon-512.png` | app icon (apple-touch-icon, stores, PWA) |
| `untzel-icon-rounded-512.png` | rounded PNG icon for social networks and presentations |
| `untzel-mark.svg` | the wave alone, no background |
| `untzel-wordmark-dark.svg` | wordmark for dark backgrounds (white letters) |
| `untzel-wordmark-light.svg` | wordmark for light backgrounds (`#0B0B0C` letters) |
| `untzel-lockup-techno-inspire-dark.png` | Techno Inspire logo + divider + wordmark, for dark backgrounds |
| `untzel-social-github.png` | the repository's GitHub social preview, 1280 × 640, `#0B0B0C` background with the wordmark and the tagline |

Rules: the wave is always `flare`; never recolor, rotate or separate the "un" from the rest of
the name. The wordmark is a drawing, not text: do not recompose it in a font. Minimum wordmark
height 16 px; the icon stays legible at 16 px. The combined lockup exists only on dark, because
the Techno Inspire logo exists only in white and cannot be recolored.

Copies served by the app in `apps/web/public/brand/`: `untzel-wordmark-dark.svg` (title of the
top bar) and `untzel-lockup-dark.png`, the combined lockup cropped to the ink (880 × 136), used
as the mark on every video frame and on the end card.

## Instrument model names

The instruments have their own model names (AURA Grand, FLUX M24, VOLTA K9 and the others), with
the full table on the [Instruments page](https://untzel.com/docs/instruments). They are
Techno Inspire trademarks and follow [`TRADEMARKS.md`](../TRADEMARKS.md). None of them uses a
manufacturer's name or logo.
