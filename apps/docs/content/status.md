## What a mark means {#marks}

**Available now** means this build has the feature. **Planned** means it is designed, but this build does not have it: a button for it may be on screen and do nothing yet. Nothing on these pages is promised with a date.

## One release, two addresses {#releases}

The app at `app.untzel.com` and these docs at `untzel.com/docs/` come from the same release, made from one version tag ([For developers](developers.md#releases)). The marks on this page therefore describe the app you open from its button.

## Instruments of this build {#instruments}

The [Instruments](instruments.md) page is generated from this build, so it lists exactly the instruments you can use today, and the [Cookbook](cookbook.md) and the AI prompt use only those.
