## O que cada marca quer dizer {#marks}

**Disponível agora** quer dizer que este build tem o recurso. **Planejado** quer dizer que ele está desenhado, mas este build não o tem: um botão dele pode estar na tela e ainda não fazer nada. Nada nestas páginas é prometido com data.

## Uma release, dois endereços {#releases}

O app em `app.untzel.com` e esta documentação em `untzel.com/docs/` saem da mesma release, feita a partir de uma tag de versão ([Para desenvolvedores](developers.md#releases)). Por isso as marcas desta página descrevem o app que você abre pelo botão dela.
