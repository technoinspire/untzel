# Getting help

| You want to | Go to |
|---|---|
| learn the app, the language and the instruments | the docs at [untzel.com/docs](https://untzel.com/docs), in English and Portuguese |
| ask a question or share something you made | [Discussions, Q&A](https://github.com/technoinspire/untzel/discussions/categories/q-a) |
| report a bug, a sound that is off or a docs mistake | [a new issue](https://github.com/technoinspire/untzel/issues/new/choose), using one of the forms |
| suggest a feature | [a feature request](https://github.com/technoinspire/untzel/issues/new/choose) |
| report a security problem | privately, as [`SECURITY.md`](SECURITY.md) explains; never in a public issue |
| contribute | [`CONTRIBUTING.md`](CONTRIBUTING.md) |

Issues and discussions are welcome in English or Portuguese.

## What is not support

- Help with your own fork, a custom build or hosting your own copy beyond what the docs
  cover.
- Music lessons: the docs and the [Cookbook](https://untzel.com/docs/cookbook) show what the
  language does, not how to write a song.
- Priority answers: Untzel is maintained by a small team, and every question is answered as
  time allows.
